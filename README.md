# 青衡 · A 股大波段量化研究台 v2

不对接交易的单标的技术面研究与回测系统。浏览器内计算，支持真实 5 分钟、15 分钟及日线 CSV；大波段策略以日线趋势为主、分钟线确认入场。

## 运行与验证

- 在本目录运行 `python -m http.server 8080 --directory dist`，打开 http://localhost:8080。
- 运行 `node --test tests/engine.test.mjs` 验证因果性、多周期、T+1 与资金核算。
- 应用无外部 JavaScript 运行依赖；较大回测在 Web Worker 内执行。UI 自动化脚本为当前环境的 Playwright 验证脚本。

## 策略与周期

默认大波段：完整日线 MA20 > MA60、收盘 > MA60 且突破此前 20 日最高价；上一根执行周期 MA10 > MA30 且收盘高于 MA10 后，在下一根开盘入场。持仓不因分钟均线短暂转弱退出，主要按已完成日线收盘跌破 MA20 或 ATR14 × 3 跟踪止损离场。ATR 跟踪以持仓期间最高已完成收盘价为基准，固定止盈默认关闭。平仓当天及其后 3 个样本交易日不再建仓。

另外保留执行周期双均线、MACD、RSI 和布林带研究。指标窗口明确以“日线交易日”或“执行周期根数”计。

5 分钟真实数据可聚合为 15 分钟或完整日线；15 分钟可聚合日线，不反推 5 分钟；禁止日线插值成分钟。午休不补线。聚合只输出已经具备全部子 K 线的目标 K 线。

## 防未来数据约束

1. 时间戳为 **北京时间的 K 线结束时刻**。一根分钟 K 线的执行开盘时刻 = 结束时刻 - 周期；日线开盘以 09:30 表示，日线收盘以 15:00 表示。
2. 第 i 根开盘决策只使用第 i-1 根及此前已经完成的 K 线。决策之后，第 i 根收盘才更新净值与下一根信号。
3. 每日汇总只有在当日 15:00 后才能被使用。盘中不能读取本日最终日线，日线信号使用上一已完成交易日。缺少上一完整交易日时，不开新的大波段仓位。
4. 突破窗口取信号日之前 N 日最高价，明确排除信号日自身。ATR 使用已完成日线的递推值，跟踪峰值使用已完成的收盘。
5. 开盘估算价仅使用当根开盘、不利滑点和开盘已知的涨跌停价。**不以当前整根高低价裁剪，也不使用当前收盘或整根成交量判断开盘是否成交。** 模型费用参考价可超出该根事后实际高低，属于成本估算，不声称实际撮合价。
6. `halted`、`prev_close` 与每日限价是“开盘已知”的输入契约，CSV 数据提供者需确保这一点。时序断言和回归测试无法验证外部数据的真实可得性。
7. 导出逐笔 `signalTime`、`dailySignalTime` 和 `executionTime`。运行中检查信号时刻不晚于开盘执行时刻。测试还包含截断历史/追加未来、修改当日尚未发生数据后检查已有交易不变。
8. 外部复权价格也需使用当时可得口径。系统不从后续事件反推历史调整因子，也不自动保证导入的复权序列具备此属性。

v1 的成交逻辑曾使用当根事后高低价及成交量，v2 已移除。浏览器里旧记录标记“旧版口径”，请用 v2 重新运行。

## CSV 格式

UTF-8，最多 25 MB / 120,000 根 K 线。

```csv
datetime,open,high,low,close,volume,prev_close,halted
2024-01-02 09:35,10.00,10.03,9.98,10.01,15000,9.99,0
2024-01-02 09:40,10.01,10.04,10.00,10.02,13000,9.99,0
```

- 必填 `datetime`（或 `date`）、原始未复权 OHLC、volume（股）。日线时间为 YYYY-MM-DD。
- 5 分钟结束时间为 09:35…11:30、13:05…15:00；15 分钟为 09:45…11:30、13:15…15:00。**不接受以开盘时刻标记的分钟 CSV**，请先统一结束时刻。
- `halted`：可选的开盘已知停牌状态，0/1；零成交量行必须提供 1。普通正成交量行缺省视为可交易。这仍是简化的流动性假设。
- `signal_close`：可选的当时可得复权收盘价，仅用于指标与趋势。必须覆盖每行。
- `prev_close`：上一交易日交易所昨收，同一天内应恒定，不能填上一分钟收盘。
- `limit_up,limit_down`：可选、成对提供的当日真实限价，优先于默认涨跌停比例。
- 自动按时间排序，拒绝重复时间、非有限数值、异常 OHLC、混合日线分钟与不对齐时刻。
- 完整交易日应有 48 根 5 分钟或 16 根 15 分钟。缺失/部分日线不会用于趋势信号，界面展示数量提示，不对缺失值向后填充。
- 开始日期前，大波段策略需要完整日线指标预热；60 日窗口需要 60 个完整交易日，而非 60 根分钟线。

演示分钟行情按固定种子独立合成，不是日线插值或真实证券数据。演示日历只排除周末。

## A 股执行、成本与绩效

100 股整数倍买入、只做多、不加仓；卖出可全仓。T+1 比较交易日期，当天买入不能在当天后续分钟线卖出。风险触发退出会保留到后续可卖出时刻，停牌和限价可进一步延迟成交。

开盘涨停不买、开盘跌停不卖。默认限价取交易所昨收或前一**交易日**收盘，分钟线不取前一根分钟收盘。ST、历史规则变化与新股无涨跌幅限制等请提供真实逐日限价。

佣金、最低佣金、双边过户费、卖出印花税在整个回测区间使用用户设置的固定费率。止损止盈/ATR 在已完成 K 线确认后，下一可成交开盘执行；跳空和 T+1 会造成实际亏损超出阈值。ATR 倍数及止损止盈参数设 0 表示禁用。

净值 =（现金 + 持仓 × 当根收盘）/ 初始资金。最大回撤覆盖全部分钟点；年化收益按 252 / 实际样本交易日计数，夏普与波动率采用每天最后一个样本的资产收益与样本标准差，无风险利率 0。部分交易日的最后可得分钟视为该日末样本，数量会提示；正式研究建议使用完整交易日。

胜率仅统计完整平仓交易，盈亏比为盈利总额 / 亏损总额；无亏损时为空值。平均持仓天数按样本交易日计算。期末不强制平仓，标的基准为首根开盘买入持有、不扣费。

## 参数验证与记录

参数比较按时间顺序前 70% 交易日训练、后 30% 验证。大波段比较日线长均线 60/90/120 与 ATR 倍数 2/3/4；其他策略比较执行周期双均线 5/10/20 与 30/60/90。排序只看训练收益，点击“回测验证段”会载入验证起止日期。验证段固定参数、空仓重新开始；之前行情只用于预热，没有跨区间继承持仓。反复据验证结果调参会降低独立性，请换新的验证集。

最近 20 次参数与指标只保存在本机 localStorage；行情文件刷新后不保留。JSON 报告保存已完成回测对应的原始行情快照，切换标的但未重新运行时，导出仍对应上次结果。CSV 明细包含信号与成交时刻。

## 限制

尚未处理分红、送转、退市清算、日内真实撮合顺序、盘口队列、成交量冲击或多股票组合。不完整市场交易日历无法自动识别，统计以 CSV 的样本交易日期为准。涉及除权除息时请提供真实昨收与限价；即使导入复权指标价格，资产仍按原始价格计价且不补现金分红。所有研究结果不保证未来表现。
