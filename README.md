## 研究流程

默认波段：完整日线MA20>MA60、短均线上行、连续2日收盘站上MA20、突破之前20日最高价，前根执行周期MA10>MA30且收盘>MA10；距日线MA20不超过2ATR、开盘缺口不超过3%，下一根开盘估算成交。日线MA20转弱或ATR14×3跟踪止损退出；固定止盈默认关闭，前根收盘止损8%，平仓后冷却3个交易日。入场过滤不保证盈利，T+1、跳空和停牌可能使损失超过止损阈值。

5分钟只能聚合到15分钟/日线；15分钟不能反推5分钟；日线不能拆成分钟。午休不填充，完整日线在15:00后可见，突破窗口排除信号日。开盘执行仅用开盘价、不利滑点和开盘已知限价/状态，不读取当根最终高低收或成交量。估算成本价可超出事后真实高低价，不模拟盘口排队、冲击与真实委托延迟。

参数按时间前70%训练、后30%验证，验证重新空仓、以前行情仅预热。默认训练评分侧重95% Wilson胜率下界，加有限收益、回撤权重；训练至少20笔已平仓、期望盈亏为正、盈亏比≥1.2、回撤≤20%。评分和排序不使用验证结果。也保留仅训练收益对照。没有达标参数时不推荐；少量全赢不当成可靠高胜率。Wilson假设样本独立，交易相关性会削弱统计置信。显示最差单笔、未实现亏损与样本数，不用拖延止损隐藏亏损。反复依据验证数据调参后需更换未见样本。

## 分仓与做 T

默认不启用 T，使用底仓 + 趋势加仓：初始底仓上限40%，每次加仓最多20%，最多2次、间隔至少2个交易日。相对上次核心买入价继续上行1个已完成日线ATR，日线趋势和分钟确认仍有效才加仓，不下跌补仓。总仓位上限95%，T方案预留10%机动空间。按固定止损 / ATR跟踪止损中较高的有效保护位，把所有可卖和锁定股份的预估损失控制在净值2%的风险预算内；预算不涵盖保证成交，跳空、停牌和费用可使实际损失更大。

正T在前根价格低于分钟均线且已转向上时买入，数量不超过旧仓可卖股数；反T在高于分钟均线且已转向下时先卖旧仓，至少保留初始底仓股数的75%，等待回落回补。没有裸卖空或当日新股卖出。每次买入独立T+1锁定，卖出按FIFO扣旧股，所有现金和权益只有一份账本。

仅在日线趋势有效时开T；目标价差与开盘距已完成分钟均线的空间取较小值，超过双边五项费用 + 双边滑点的2倍才尝试。默认目标0.5%、不利价差1%止损、最长12根、每天最多开2次；14:30后不开T，15分钟于14:45 / 5分钟于14:55尝试收束。止损、超时仍按下一开盘成交，可能亏损。趋势 / ST / 成分调出离场优先，先卖所有可卖旧股，剩余新股继续锁定；未配对或无法回补明确披露。跨除权日取消T价差配对，实际库存和登记权益继续留在波段账本，不虚构套利利润。

仓位方案对照比较仅底仓、加仓、加仓+正T、加仓+反T、加仓+择向T，共5种。相同资金、费用、初始风险预算，训练段只按波段交易质量排序；验证段独立空仓开始，不用验证结果推荐。T两腿净价差只作为审计指标，已计入总净值，不能再相加或当成超额收益。整个波段闭合现金流统计胜率；收益率分母为核心与加仓投入（不反复累加T周转），期末未闭合波段盈亏包含所有买卖和权益，不掩盖亏损。

## 交易规则

- 主板普通10%；主板ST在2026-07-06前5%，之后10%。创业板2020-08-24前普通10%/ST5%，之后20%；科创板20%；北交所30%。真实日限价优先，分红日基准使用交易所除权参考价，不取上一分钟收盘。
- 主板/创业板100股整手；科创板200股起、1股递增，研究限价申报上限10万股；北交所100股起、1股递增，上限100万股。只做多；底仓、加仓与 T 使用共享逐批库存，卖出允许清理余股；T+1按交易日期，锁定红股上市前不能卖。
- IPO首5日等无限价规则按板块/上市日期/上市交易日识别，默认上市前20个交易日不新开仓。特殊复牌、退市整理等必须有真实限价或明确无限价，未知规则拒绝推算。
- 历史ST不新买；已有持仓进入ST或被已知历史沪深300名单调出，等待T+1与可成交开盘退出。无法用今日ST列表代替历史状态。
- 沪深300官方接口按周更新：按查询日缓存300只成员，updateDate不可晚于查询日。保守认为更新日15:00后才可得，刷新日不新开仓，下一个可知开盘应用新名单。只能证明供应商周粒度内成员，不能冒充指数公司逐事件生效/公告时间。
- 默认资金100万元，五项用户费率分开按每笔执行计算，均可编辑：佣金0.005%（万0.5），每笔最低5元；印花税0.05%（万5）仅卖出；经手费0.00341%、证管费0.002%、过户费0.001%均双边。不视为佣金包含规费。默认固定费率；同价各买卖100万元费用728.20元，不含滑点。可选历史印花税/过户费模式，自动费率表覆盖2015-08起。2022-04-29前沪深过户费0.002%、北交所0.0025%，之后0.001%；2023-08-28前卖出印花税0.1%，之后0.05%。历史模式不自动改变佣金、经手费或证管费；固定费率是用户情景，不冒充所有历史日期的实际费率。

## 完整数据准入与权益

数据包 `schemaVersion=1`，包含metadata、bars、daily、calendar、universe、actions、factors。metadata声明请求区间（含预热）、显式板块、上市日期、周期、raw原始价、shares股单位、Asia/Shanghai时区与bar-close结束时间，并给出各来源覆盖。逐交易日校验整日缺失、48/16根分钟网格、重复/OHLC、独立日线收盘/成交量、ST与停牌开盘状态、除权参考价、公司行动与连续因子链、供应商因子相对变化、历史成分和修订冲突。不得悄悄缩短请求区间或向前填缺失数据。停牌日无分钟时仅使用独立日线估值点，非成交K线，参与日收益计数，不虚构成交。

原始价成交和估值；连续指标价按前日原始收盘/当日交易所参考价从除权日累积，不因未来事件重写过去。固定止损同样用连续价格。供应商前复权全序列不直接用作历史当时可得的信号。

登记日股数决定权益；除权日确认应收股息和锁定红股，到账/上市日才释放现金/可卖股。卖出原始持仓后权益继续保留，全部结算后才计完整平仓盈亏。默认股息税前或事件明确的税后金额，不计算个人持有期补税；红股逐权益向下取整，无虚构补偿。未结算权益参与期末估值，基准同样核算公司行动并保留买整股后的现金，不扣费。

因子事件缺失对应账务，或现金/送转与参考价不符，均阻止正式回测。配股认购账务未支持，明确阻止，不默认外部资金。退市清算、复杂重组和真实盘口撮合未模拟。所有完整性结论仅说明所声明数据源内的结构/覆盖，不证明供应商绝对无漏报、历史信息可得性或统计未来胜率。
