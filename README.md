# 青衡 · A 股量化研究台

不对接交易的单标的日线技术面策略辅助回测系统。无第三方运行依赖，所有行情解析和回测在浏览器执行。

## 使用

在本目录运行 `python -m http.server 8080 --directory dist`，浏览器打开 http://localhost:8080。模块需要 HTTP 访问，请勿直接双击 HTML。

双均线、MACD、RSI、布林带策略；参数比较；CSV 导入；交易记录、净值/回撤图、收益与风险指标；JSON 报告与 CSV 成交记录导出。最近 20 次回测的参数与指标保存在本机 localStorage，行情文件刷新后不保留。

## 行情格式

UTF-8 CSV 必须包含 `date,open,high,low,close,volume`。date 为 YYYY-MM-DD，OHLC 是原始成交价格，volume 单位为股。可选 `signal_close`（复权信号价格）、`prev_close`（交易所昨收）、`limit_up,limit_down`（成对提供每日真实限价）。拒绝重复日期、非有限数值、价格关系无效以及不完整复权信号。最多 12,000 行、2 MB。至少要为所选策略提供完整预热区间。

演示行情由固定随机种子生成，非真实证券数据；演示交易日只排除周末。

## 回测口径与限制

只使用前一条日线及之前的数据生成信号，下一日开盘成交。100 股整数倍买入、T+1、无做空，零成交量停牌；开盘涨停禁止买入、跌停禁止卖出。CSV 限价优先，否则使用指定固定比例与昨收，无法自动识别上市初期、ST 与历史制度变更。

仓位按可用现金配置，买入滑点上调卖出下调，成交价限于当日价格范围与限价。最低佣金、双边过户费、卖出印花税均固定在用户指定费率，不随历史日期自动改变。止损止盈收盘触发后下一日开盘执行，期间跳空可使实际损失超过阈值。

期末持仓按收盘价计价，不强制卖出。胜率只统计完整平仓交易；盈亏比为盈利总额/亏损总额，无亏损时显示空值。年化收益按 252/样本日数指数计算，夏普使用所有日收益、样本标准差与无风险利率 0。基准为首日开盘买入持有，不扣费用。

尚未处理分红、送转股、退市清算、撮合排队、成交量冲击、日内风控与多标的组合。除权除息股票需提供准确昨收与限价；即使使用复权 signal_close，资产仍按原始价格计算且未补偿现金分红。CSV 缺失交易日无法自动识别。参数排序为样本内比较，不构成未来绩效保证。
